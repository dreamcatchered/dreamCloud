API Documentation

Upload files seamlessly using our API.

Endpoint: POST /upload

Headers:

  • x-api-key: Your API Key

Body:

  • file: The file to upload (multipart/form-data)

Example Request:

curl -X POST \
  -H "x-api-key: YOUR_API_KEY" \
  -F "file=@yourfile.jpg" \
  https://cloud.dreampartners.online/upload

Example Response:

{
  "file_id": "a1b2c3d4e5f6",
  "url": "https://cloud.dreampartners.online/file/a1b2c3d4e5f6"
}
